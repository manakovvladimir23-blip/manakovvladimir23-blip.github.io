MANAKOV PRODUCT — V3

Структура:
index.html
images/

В этой версии изображения не растягиваются:
- каждый визуал имеет свой aspect-ratio;
- object-fit используется только там, где это безопасно;
- на мобильном изображения перестраиваются в одну колонку;
- основной сайт использует WebP, PNG оставлены как резерв;
- изображения слегка перешарплены без искусственного увеличения.

Для GitHub Pages:
1. Загрузить index.html в корень репозитория.
2. Загрузить папку images целиком в корень репозитория.
3. Старый index (1).html удалить.
4. Старые отдельные картинки в корне можно удалить — используются images/.
