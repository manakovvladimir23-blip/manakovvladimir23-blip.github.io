MANAKOV PRODUCT V4

Готовая статическая версия сайта.

Структура:
index.html
images/

Для GitHub Pages:
1. index.html должен лежать в корне репозитория.
2. Папку images загрузить рядом с index.html.
3. Старый index (1).html удалить.
4. В Settings → Pages оставить Deploy from a branch → main → /(root).

Изображения подготовлены в WebP и имеют несколько размеров для компьютера и телефона.
Основные изображения не растягиваются: для блоков заданы фиксированные пропорции, object-fit и width/height.
